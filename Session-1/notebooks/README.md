# Notebook guide

## Guided lesson

Open `01_live_coding_student.ipynb` during the live session. It follows the
complete machine-learning workflow and leaves important code and explanations
as TODO tasks.

## Independent assignment

Complete `02_week_1_assignment.ipynb` after the guided lesson. Before
submitting it, restart the kernel and run every cell from top to bottom.

Start JupyterLab from the `Session-1` directory so relative data and image
paths resolve correctly:

```bash
python -m jupyter lab
```

After dependencies are installed, the notebooks do not require internet
access.
