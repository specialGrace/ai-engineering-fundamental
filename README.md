# AI Engineering Fundamentals

This is the student repository for the Ormedian AI Engineering Fundamentals
programme, taught by Samuel Adebayo, PhD.

The repository contains guided lesson notebooks, independent assignments,
educational datasets, supporting Python code, tests and learner reference
material. Instructor solutions and teaching notes are intentionally excluded.

## Course sessions

- [Session 1: Machine-learning foundations](Session-1/README.md)

## Getting started

```bash
cd Session-1
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m jupyter lab
```

On Windows PowerShell, activate the environment with:

```powershell
.venv\Scripts\Activate.ps1
```

Open `notebooks/01_live_coding_student.ipynb` for the guided lesson or
`notebooks/02_week_1_assignment.ipynb` for the independent work.

## Working agreement

- Complete TODOs in your own words and code.
- Do not commit secret keys, personal data, virtual environments or generated
  model artefacts.
- Run the tests before submitting work.
- Make small, understandable Git commits.
- Be ready to explain every submitted line.
